# groceries-budget-plan
 Household Grocery Budget Planner

## Introduction
Household Grocery Budget Planner is a very easy Python
application that aids in calculating grocery expenses and
managing the budget for household grocery shopping.

## Features
- Takes a household grocery budget as an input
- Calculates cost of various grocery items
- Prints out the shopping receipt
- Verifies whether the expenditure is more than the budget
- Calculates remaining budget or extra budget required

## Technologies Used
- Python 3
- Variables and user input
- Arithmetic operations
- Conditional statements

## Steps to Run
1. Install Python 3.
2. Clone this repository.
3. Navigate to the project folder using a terminal.
4. Execute: python3 grocery_budget.py

## Purpose
This application showcases the use of programming concepts of
Python in real-life applications.
